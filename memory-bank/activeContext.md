### Ack-alert Tier 1 — stale unacknowledged High/Critical surfacing (done this session)
Driver: a **real gap**, not cosmetic. `today.unacknowledgedHighPriority` is scoped to the current operational day, so a Critical handover left unacknowledged across a shift/day boundary silently dropped off the dashboard. The new `ackAlert` surfaces it **regardless of date**.
- **New `backend/src/services/ackAlert.service.ts`** — pure `classifyAckAlert(priority, ageMinutes, thresholds?)` → `'none' | 'warn' | 'breach'`. Thresholds default `criticalBreachMinutes: 15`, `highWarnMinutes: 60` (single knob, `DEFAULT_ACK_ALERT_THRESHOLDS`). Critical < threshold = `warn`, ≥ = `breach`; High < threshold = `none`, ≥ = `warn`; Low/Normal always `none` (BR-10 scope). NaN age floored to 0; negative age floored to 0; Infinity (very old) naturally breaches — safer for aviation.
- **`backend/src/services/dashboard.service.ts`** — added 4 SQL subqueries with **no today filter**: `staleUnackedCriticalCount`, `oldestUnackedCriticalMinutes`, `staleUnackedHighCount`, `oldestUnackedHighMinutes` (age via `FLOOR(EXTRACT(EPOCH FROM (now - MIN(createdAt))) / 60)::int`). New `buildAckAlert(row, thresholds?)` helper rolls per-priority into one severity (max of Critical/High via `ACK_ALERT_SEVERITY_RANK`) + `emptyAckAlert()`. Exposed `ackAlert` at **top level** of `getDashboardSummary` return (next to `carriedForwardCount`). Old `today.unacknowledgedHighPriority` left UNCHANGED on purpose (additive — banner doesn't break, minimal test churn).
- **`tests/unit/services/ackAlert.service.test.ts`** — 9 tests, all pass. Dashboard test updated with realistic stale mock (Critical 2 @ 45min → breach, High 1 @ 30min → none) → `ackAlert: { severity: 'breach', unackedCount: 3, criticalCount: 2, highCount: 1, oldestUnackedMinutes: 45 }`.
